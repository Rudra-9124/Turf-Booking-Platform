# Turf Booking Platform

## Overview

The Turf Booking Platform is a web application that simplifies sports turf bookings for activities like football and cricket. Built with **Django** (backend), **MySQL** (database), and **React** (frontend), the platform allows users to browse available turfs, book time slots, and make secure payments. Turf owners and admins can efficiently manage turfs, bookings, and user interactions.

## Features

* **User Authentication:** Secure login/signup with Django’s authentication system.
* **Turf Browsing & Slot Booking:** View available turfs and book slots with integrated payments.
* **Admin & Owner Modules:** Manage turfs, bookings, and users with an admin panel.
* **Responsive Design:** Mobile-friendly interface using React and Tailwind CSS.

## Technologies Used

* **Frontend:** React, Tailwind CSS
* **Backend:** Django, Django REST Framework
* **Database:** MySQL
* **Payment Gateway:** Static
